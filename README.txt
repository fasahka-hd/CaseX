=== КАК ЗАПУСТИТЬ САЙТ ===

1. Распакуй эту папку куда угодно.
2. Запусти файл start.bat (двойной клик)
3. Браузер откроется автоматически по адресу http://localhost:8000

ВАЖНО: НЕ открывай index.html напрямую через двойной клик!
Он должен запускаться ТОЛЬКО через start.bat

Если Python не установлен — установи его или используй Live Server в VS Code.
