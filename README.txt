=== КАК ЗАПУСТИТЬ САЙТ ===

1. Установи Node.js (https://nodejs.org) — если ещё не установлен.
2. Открой папку проекта и выполни в терминале:

   npm install
   npm start

   (или просто: node server.js)

3. Открой в браузере: http://localhost:3000

ВАЖНО: НЕ открывай index.html напрямую через двойной клик!
Он должен запускаться ТОЛЬКО через сервер (node server.js),
потому что сайт использует API (/api/*), живой стрим событий (SSE)
и Steam OpenID (вход).

=== ВХОД ===

Вход — ТОЛЬКО через Steam (OpenID):
- Кнопка «ВОЙТИ ЧЕРЕЗ STEAM» ведёт на steamcommunity.com,
  там игрок подтверждает вход, и сайт получает его профиль.
- Никаких ников и паролей. Steam ID — единственный идентификатор.
- Данные профиля (имя, аватар) берутся из публичного профиля Steam.
- На локальной машине (localhost) Steam тоже работает.
  Для боевого домена ничего настраивать не нужно —
  адрес возврата определяется автоматически по хосту.

=== ОНЛАЙН ===

Счётчик «онлайн» — НАСТОЯЩИЙ: это количество активных
подключений к серверу (SSE-соединений). Нет никакой имитации.

=== ЧЕСТНОСТЬ ===

- Нет фейковых анимаций: никаких рулеток, крутящихся колёс и лент.
  Все результаты мгновенные.
- Нет ботов: лента дропов наполняется только реальными игроками.
- Апгрейд: шанс = ставка ÷ цена цели (математика честная, RNG серверный).
- Кейсы: шансы фиксированы в коде (weights), RNG серверный.
- Кража скина: 15-секундный таймер, комиссия 4%, PvP-миниигры
  (монетка / кости / реакция) — реальный выбор игрока.

=== О ПРОЕКТЕ ===

Дизайн по макету: фон #272727, панели #444444, мята #74FFCA,
шрифт в стиле Druk Wide Cyr (Oswald с кириллицей в комплекте).

Главная — апгрейды: круг апгрейда с шансом по центру, кнопка АПГРЕЙД,
слева сайдбар (онлайн, статистика, инвентарь), снизу панели
«Мои предметы» и «Выбрать предмет».

Механики:
- Апгрейд: свой предмет (и/или баланс) + цель → честный шанс → результат
- Кейсы CS2 (8 кейсов, 70+ предметов)
- STEAL A SKIN: кража дорогих дропов с PvP-битвой
- Акции: «Потрать 1000 ₽ — получи 500 ₽», бонусы за депозит
  (от 1000 ₽ — +10%, от 5000 ₽ — +15%, от 10000 ₽ — +20%)
- Ежедневные награды, инвентарь, живая лента удачи

Структура:
- index.html            — оболочка SPA
- static/css/main.css   — дизайн-система по макету
- static/js/main.js     — весь фронтенд (SPA, SSE)
- server.js             — бэкенд: API, Steam OpenID, STEAL-механика, апгрейды
