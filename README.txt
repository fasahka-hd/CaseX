=== КАК ЗАПУСТИТЬ САЙТ ===

1. Установите Node.js 18 или новее.
2. В папке проекта выполните:

   npm install
   npm start

3. Откройте http://localhost:3000

Не открывайте index.html двойным кликом: сайту нужен server.js и API.

=== ВАЖНО ОБ ИНВЕНТАРЕ ===

Steam используется только для авторизации пользователя.
Steam-инвентарь не загружается.

Инвентарь сайта хранится в SQLite (таблица site_inventory). В нём находятся
только скины, полученные из кейсов и успешных апгрейдов на сайте.

Вкладка ▦ показывает весь инвентарь сайта.
Вкладка 🔥 показывает предметы редкости «Засекреченное» и выше.
Цена отображается на каждой карточке. Нижняя полоса имеет цвет редкости.

=== КЕЙСЫ И АПГРЕЙДЫ ===

Результаты рассчитываются сервером. Открытие кейса, списание баланса и
добавление предмета выполняются одной SQLite-транзакцией. При апгрейде
исходный предмет используется, а при победе цель добавляется в инвентарь сайта.

У нового игрока доступен один бесплатный стартовый кейс.

=== НАГРАДЫ ===

Панель еженедельного набора использует оригинальные assets:
chunks/bg.webp и chunks/question.svg.

=== ЛОКАЛЬНЫЙ PREVIEW-БЕЗ STEAM ===

Только для разработки:

   ALLOW_DEV_LOGIN=1 npm start

После этого можно открыть /auth/dev. Без переменной ALLOW_DEV_LOGIN этот
маршрут не создаётся.

=== ДОПОЛНИТЕЛЬНО ===

Кейсы открываются на отдельной странице с анимированной лентой. Предмет можно
продать на внутренний баланс или отправить в апгрейд. Проценты 10/30/50/75
задают увеличение минимальной стоимости цели и проверяются сервером.
Перед Steam-входом необходимо подтвердить возраст и принять условия.
