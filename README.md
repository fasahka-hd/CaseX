# КЕЙСЕР — инвентарь сайта, кейсы и апгрейды

## Запуск (без Docker)

Для локального запуска Docker **не нужен**. По умолчанию используется
встроенная SQLite и кеш в памяти процесса — все функции работают сразу.

```bash
npm install
npm start
```

После запуска откройте `http://localhost:3000`.

Авторизация доступна только через Steam. Локальный адрес в `BASE_URL` не включает обходной способ входа.

> `npm start` сам пытается поднять PostgreSQL/Redis через Docker, если они
> есть в системе, но если Docker не установлен — просто остаётся на SQLite.
> Чтобы принудительно использовать SQLite, запустите:
>
> ```bash
> npm run start:sqlite
> ```

## Продакшен-переменные

Задайте их в `.env`:

- `BASE_URL` — публичный HTTPS-адрес сайта без завершающего `/`;
- `SESSION_SECRET` — длинная случайная строка;
- `STEAM_API_KEY` — необязательно, подгружает имя/аватар профиля;
- `TELEGRAM_URL` — ссылка на Telegram;
- `ADMIN_STEAMIDS` — SteamID администраторов через запятую;
- `SUPPORT_STEAMIDS` — SteamID поддержки через запятую;
- `BRAND_NAME` — название сайта в шапке.

## Запуск с Docker (по желанию)

Если Docker установлен и нужен PostgreSQL/Redis:

```bash
npm run infra:up      # поднять postgres и redis
npm start             # приложение само переключится на postgres + redis
```

Полный стек (приложение + Postgres + Redis + nginx с TLS):

```bash
cd deploy
docker compose up -d --build
```

## Что внутри

- **Инвентарь сайта** — таблица `site_inventory` в SQLite/Postgres.
  Предметы появляются только после открытия кейса или успешного апгрейда.
- **Кейсы** — выпадение рассчитывается сервером через `crypto.randomInt`,
  стоимость списывается и предмет добавляется в одной транзакции.
  Стартовый кейс бесплатный и доступен один раз на пользователя.
- **Апгрейды** — исходный предмет берётся из активного инвентаря сайта,
  цель — из серверного каталога. Сервер проверяет минимум стоимости цели
  согласно выбранному проценту апгрейда (30/50/75/x2/x5/x10).
- **Награды** — еженедельная панель и лента «Топ дроп».
- **Админ-панель** (`/admin`) — пользователи, транзакции, кейсы, дропы,
  боты, промокоды, поддержка, логи и инфраструктура. Доступ только для
  SteamID из `ADMIN_STEAMIDS` и `SUPPORT_STEAMIDS`.

## Структура

```
server.js              — Express-приложение, все API-маршруты
lib/db.js              — абстракция над SQLite/Postgres
lib/cache.js           — кеш в памяти или Redis
lib/queue.js           — внутренняя очередь задач
static/js/main.js      — клиентское приложение
static/js/admin.js     — админ-панель
static/css/admin.css   — стили админки (в палитре главной)
deploy/                — docker-compose и nginx
scripts/               — запуск, миграция, инфраструктура
```
