# КЕЙСЕР — инвентарь сайта, кейсы и апгрейды

## Запуск

```bash
npm install
npm start
```

После запуска откройте `http://localhost:3000`.

## Авторизация

Steam OpenID используется **только для входа и идентификации пользователя**. Инвентарь Steam не загружается и не используется сайтом.

Для production задайте:

- `BASE_URL` — публичный HTTPS-адрес сайта без завершающего `/`;
- `SESSION_SECRET` — длинный случайный секрет;
- `STEAM_API_KEY` — необязательно, только для имени и аватара профиля;
- `TELEGRAM_URL` — ссылка Telegram.

## Инвентарь сайта

Предметы хранятся в таблице `site_inventory` SQLite. Они появляются только после:

- открытия кейса на сайте;
- успешного апгрейда на сайте.

Вкладка `▦` в сайдбаре показывает весь активный инвентарь сайта. Вкладка `🔥` показывает только предметы редкости «Засекреченное» и выше.

Каждый предмет содержит сохранённые сервером цену, редкость, цвет редкости, источник получения и состояние. Цена показывается на карточках, а нижняя полоса окрашивается в цвет редкости.

## Кейсы

- Выпадение определяется сервером через `crypto.randomInt`.
- Стоимость списывается и предмет добавляется в одной SQLite-транзакции.
- Стартовый кейс бесплатный и доступен один раз на пользователя.
- Остальные кейсы используют внутренний баланс сайта.
- Выигрыш сразу появляется в `site_inventory` и в live-ленте.

## Апгрейды

- Исходный предмет берётся только из активного инвентаря сайта.
- Цель берётся из серверного каталога.
- Шанс и результат рассчитываются сервером.
- Исходный предмет используется независимо от результата.
- При победе целевой предмет добавляется в инвентарь сайта.

## Награды

Еженедельная панель использует оригинальные файлы репозитория:

- `chunks/bg.webp` — фон панели;
- `chunks/question.svg` — вопрос в четырёх ячейках.

Лента «Топ дроп» наполняется только реальными событиями открытия кейсов и успешных апгрейдов.

## Локальная проверка без Steam

Только для локальной разработки можно запустить:

```bash
ALLOW_DEV_LOGIN=1 npm start
```

и открыть `/auth/dev`. Этот маршрут отсутствует, если переменная `ALLOW_DEV_LOGIN` не равна `1`.

## Дополнительный интерфейс

- Каталог кейсов показывает карточки с ценой и кнопкой покупки; открытие выполняется на отдельной странице с серверным результатом и анимированной лентой.
- Активный предмет можно продать за его текущую стоимость или сразу отправить в апгрейд.
- Кнопки 10%, 30%, 50% и 75% задают минимальное увеличение стоимости цели; сервер проверяет выбранный процент.
- Перед переходом в Steam пользователь должен подтвердить возраст и принять условия.
- «Топ дроп» на странице наград фильтруется по источнику `reward` и не показывает кейсы или апгрейды.
