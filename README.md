# КЕЙСЕР v2 — real-data foundation

Эта версия исправляет принципиальную проблему v1: **никаких выдуманных предметов, цен, онлайна, фида или баланса**.

## Что изменено

- Убран fake online. Показывается число реальных SSE-подключений к сайту.
- Убран fake feed. Лента пустая до реального события.
- Убран fake каталог предметов. После Steam-входа предметы берутся из реального CS2-инвентаря пользователя.
- Иконки предметов берутся из данных Steam и CDN Steam.
- Steam OpenID реализован через официальный Steam OpenID provider.
- Баланс хранится в SQLite и для нового аккаунта равен 0. Он не притворяется балансом Steam.
- Инвентарь без входа показывает:
  «У вас нет предметов» / «Откройте кейс» / «Открыть кейс».
- Страница кейсов без входа показывает «Войдите в аккаунт» + Steam.
- Telegram находится слева от баланса и использует SVG-иконку Telegram.
- Поддержка открывается встроенным чатом, а не новой страницей.
- Добавлен favicon.svg, 404 favicon исправлен.
- STEAL A SKIN не генерирует фейковые события.
- Убрана fake upgrade RNG из frontend. Production upgrade должен быть server-authoritative.

## Steam

Steam прямо предоставляет OpenID для идентификации SteamID и рекомендует использовать официальный OpenID provider. См. документацию Steam Web API.

Для production обязательно:
1. Настроить HTTPS.
2. Указать BASE_URL, например https://site.ru.
3. Сгенерировать SESSION_SECRET.
4. При необходимости добавить STEAM_API_KEY для профиля.
5. В Steam OpenID realm/return_to должен совпадать с реальным доменом.

## CS2 inventory

Используется официальный публичный inventory endpoint Steam:
`https://steamcommunity.com/inventory/{steamid}/730/2`

Steam inventory может быть приватным или ограничиваться Steam. В таком случае сайт честно покажет ошибку вместо фейковых предметов.

## Баланс

Steam не предоставляет «баланс сайта». Поэтому баланс является внутренним балансом БД сайта. Сейчас для новых пользователей он 0. Реальные пополнения нужно подключать к платёжному провайдеру и зачислять только после подтверждения платежа сервером.

## Важно

Этот билд намеренно не подменяет отсутствующие production-интеграции фейками. Перед запуском денег/трейдов необходимо подключить:
- платежи;
- реальный каталог кейсов;
- серверную экономику;
- Steam trading backend;
- server-authoritative upgrade;
- real-time live drops;
- антифрод;
- журнал транзакций;
- rate limiting.
